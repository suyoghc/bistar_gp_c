(a) `pw_nll` discards `cov_psi` entirely (`mu_p, _ = _extract_marginals(mu_psi, cov_psi)`, `bistar_gp/bms_star.py:185`) and weights by the *candidate's* isotropic noise (`cov = noise_var * np.eye(n)`, `experiments/practice_EvansEtAL/candidates.py:105-113`), whereas `pw_kl_vcal` weights by the *GP's* variance (`bistar_gp/metrics_v2.py:43-55`; `docs/paper-sie-jmp/00-notation.md:14` "GP-uncertainty-weighted MSE"), so `pw_mse` is the closer analogue, not `pw_nll`. 4. **[S2] [experiments/regret_curves_mopen.py:115-172, 471-481; section:106-121, 137-141]** — the reconstructed ensemble is not the binding estimand and is not the ensemble that produced the stored G. The kb formula is `regret_theta(t) = E_HMC[|mu_GP(t) - mu_theta(t)|]` — an average of *posterior mean functions* over hyperparameter draws, matching the practice run's psi objects, which are `(mean, cov)` predictive distributions per draw (`extract_gp_predictives`, `bistar_gp/bms_star.py:219`). The script instead averages 100 random *latent function draws* at one fixed MAP point (`draws_normalized = mean[None,:] + standard_normal @ factor.T`, line 166). By Jensen this strictly inflates every reported regret by roughly the per-trial latent posterior SD, and because the absolute value is not linear the inflation does not cancel in the candidate gap — it compresses the gap by a trial-dependent amount, which is exactly the quantity the "localization" claim reads. The section discloses the MAP-vs-HMC substitution (lines 141-148) but never the mean-vs-function-draw substitution, then asserts "Regret therefore explains both sides of the aggregate result" (line 137). **Fix:** state the substitution, report the mean-based regret alongside (the code already holds `posterior_mean` at line 148), and soften "explains" to a consistency claim.
