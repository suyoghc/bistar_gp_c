4. [S3] [docs/paper-sie-jmp/03-case-A-external-validation.md:48-51] The displayed Laplace result Z_M ≈ p_M(θ*)√(2πτ/G''(θ*)) is incomplete as stated — Laplace gives Z_M ≈ p_M(θ*)·exp{−G(θ*)/τ}·√(2πτ/G''(θ*)), and the omitted exponential is only unity because the point data prior at 1/2 is exactly attainable in the Bernoulli family, so G(θ*)=0 (the script correspondingly integrates exp(−(G − G.min())/τ)). As written the equation is wrong for any data prior the candidate family cannot match exactly, and "the remaining common terms cancel" papers over it. The rest of the argument is sound and quantitatively corroborated: the residual scales as O(τ) (4.9×10⁻², 6.4×10⁻⁴, 6.4×10⁻⁶, 6.4×10⁻⁷ at τ = 10⁻², 10⁻⁴, 10⁻⁶, 10⁻⁷). Fix: either carry the exp{−G(θ*)/τ} factor in the display or append "with G(θ*)=0 at this point data prior".
