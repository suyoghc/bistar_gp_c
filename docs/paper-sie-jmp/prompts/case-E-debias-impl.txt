drift as the bias process, exactly the thesis's composite-process story.

   into the SE (truth-candidate) component and the linear (bias-candidate)
   component via the package decomposition. Record decomposition
   success/failure counts.
3. DEBIAS by marginalization: the debiased posterior predictive of the true
   process = the SE-component posterior with the linear component
   marginalized out (averaged over draws). Produce:
